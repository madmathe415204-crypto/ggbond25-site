# GGBOND-25

My first AI-powered personal website: a cyber-pixel identity interface built with React, Vite, Three.js, React Three Fiber, Rapier physics, GSAP, OGL particles, and local media assets.

## Features

- Animated hero with local intro video
- Interactive 3D lanyard badge unlock flow
- Scroll-reactive video background, particles, and pixel cursor trail
- Dossier, skill stats, growth route, locked archive, and contact signal sections
- Responsive layout for desktop and mobile

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Verify

```bash
node tests/site-structure.test.mjs
```
